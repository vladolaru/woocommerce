## Compatibility conclusion

Reference contract: the primary transaction details `id` is not necessarily a Stripe balance transaction ID. It is normally `pi_*`; `ch_*`/`py_*` is a supported fallback that the page resolves through the charge endpoint and canonicalizes to `pi_*`; numeric order IDs are also supported in the reference. `txn_*` belongs in the supplemental `transaction_id` query when source data has a balance transaction, except the fees report has a fallback that may use `txn_*` as primary when no payment ID exists.

Smallest compatibility-preserving fix: keep existing native `txn_*` detail support, but add reference-compatible branching in the native transaction details page/data layer:

1. If `id` starts with `pi_`, call `/wc/v3/payments/payment_intents/{id}`.
2. If `id` starts with `ch_` or `py_`, call `/wc/v3/payments/charges/{id}` and, when the returned charge has `payment_intent`, replace the URL with `id={payment_intent}` while preserving any existing `transaction_id`, `transaction_type`, or dispute query params.
3. If `id` starts with `txn_` or only `transaction_id` is present, keep the current `/wc/v3/payments/transactions/{txn}` flow.
4. Update native transaction list link building to prefer `payment_intent_id || charge_id` for the primary `id` and append `transaction_id` separately, matching the reference list contract while retaining the detail page's existing `txn_*` support for old/bookmarked native links.
5. Update native `/woopayments/disputes/details` redirect to resolve a dispute ID via `getWooPaymentsDispute()` and redirect to transaction details with `id={dispute.payment_intent || charge_id}` and `transaction_id={charge.balance_transaction}` when present; if the URL already has `charge_id`, it can redirect directly to that charge fallback.

Avoid fixing this by changing PHP order-note builders to emit `_wcpay_payment_transaction_id`/`txn_*`: that would make new native notes fit the current native page but would break the reference WooPayments contract and leave existing `pi_*`/`ch_*` links broken.
