# WooPayments Subsystem Disposition Manifest

This manifest is the standing inventory for the WooPayments extension subsystems that native WooPayments must either port, supersede, or explicitly drop. The companion gate, `subsystem-disposition-gate.sh`, enumerates the extension source under `includes/**/*.php` and `src/**/*.php` and fails when any PHP file is missing an exact source row below.

## Disposition States

- `PORTED`: Native runtime owns equivalent behavior.
- `SUPERSEDED`: Native runtime intentionally provides equivalent product behavior through a different subsystem.
- `DROPPED`: Native runtime intentionally does not provide the behavior. Dropped rows require explicit sign-off, date, and reason before release.
